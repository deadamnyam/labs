# rabbit
## Цель: определить общее количество пар кроликов, которые останутся на n-ый месяц, если кролики живут m месяцев, по формуле последовательности Фибоначчи, которую необходимо изменить для использования алгоритмов динамического программирования.
## Задача: проанализировать рисунок динамики численности кроличьей популяции в случае смертности кроликов, изменить формулу F{n} = F{n-1} + F{n-2} для решения с помощью алгоритмов динамического программирования.
## Инструменты и алгоритмы: язык программирования Python, алгоритмы динамического программирования с линейной памятью, списки для хранения результатов, циклы для итерации по месяцам и возрастным группам.
## Ошибки: неправильная постановка пробелов; ошибки в вычислениях, так как не было указано, что первое потомство появилось сразу у первой же пары в первый месяц и дальше итерация должна происходить со 2 месяца.
## Выводы: программа безошибочно вычисляет количество кроликов, учитывая их смертность и особенности размножения.
## Результаты: при вводных данных 33 и 2 результат вычислений будет 1.

# lab2
## Цель: исследовать код, который находит все начальные позиции подстроки t в заданной строке s (ДНК-последовательности) и выводит их в виде списка чисел.
## Задачи: получить ДНК-последовательность (s) и искомые строчки(t) из ввода, найти все возможные встречные t и вывести найденные результаты через пробел.
## Инструменты и алгоритмы: язык программирования Python, Основные инструменты:
str.strip() — удаляет лишние пробелы и символы переноса строки.
str.find(sub, start) — ищет подстроку sub в строке, начиная с позиции start (возвращает -1, если не найдено).
list.append() — добавляет элемент в список.
' '.join(map(str, list)) — преобразует список чисел в строку с разделителем-пробелом.
## Алгоритм:
1)Считать строки s и t.
2)Создать пустой список positions для хранения позиций.
3)Найти первое вхождение t в s с помощью s.find(t).
4)Пока находятся вхождения (index != -1): добавить текущую позицию в список.
5)Продолжить поиск со следующей позиции (index + 1).
6)Вывести список позиций через пробел.
## Ошибки: 1) неправильный подсчет результатов, из-за того, что не было указано, что следующее вхождение t в s необходимо искать с учетом уже найденных, то есть не находить бесконечно одно и то же. исправление: index = s.find(t, index + 1)
2) невнимание к разнице между "с" и "С". исправление: использование по умолчанию верхнего регистра
## Вывод: написанная программа успешно обрабатывает вводимые ДНК-последовательности и выводит правильное количество позиций подстроки t в строке s в формате чисел через пробел.
