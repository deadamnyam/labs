# rabbit
## Цель: определить общее количество пар кроликов, которые останутся на n-ый месяц, если кролики живут m месяцев, по формуле последовательности Фибоначчи, которую необходимо изменить для использования алгоритмов динамического программирования.
## Задача: проанализировать рисунок динамики численности кроличьей популяции в случае смертности кроликов, изменить формулу F{n} = F{n-1} + F{n-2} для решения с помощью алгоритмов динамического программирования.
## Инструменты и алгоритмы: язык программирования Python, алгоритмы динамического программирования с линейной памятью, списки для хранения результатов, циклы для итерации по месяцам и возрастным группам.
## Ошибки: неправильная постановка пробелов; ошибки в вычислениях, так как не было указано, что первое потомство появилось сразу у первой же пары в первый месяц и дальше итерация должна происходить со 2 месяца.
## Выводы: программа безошибочно вычисляет количество кроликов, учитывая их смертность и особенности размножения.
## Резульаты: при вводных данных 33 и 2 результат вычислений будет 1.
