# lab2
## Цель: исследовать код, который находит все начальные позиции подстроки t в заданной строке s (ДНК-последовательности) и выводит их в виде списка чисел.
## Задачи: получить ДНК-последовательность (s) и искомые строчки(t) из ввода, найти все возможные встречные t и вывести найденные результаты через пробел.
## Инструменты и алгоритмы: язык программирования Python, Основные инструменты:
str.strip() — удаляет лишние пробелы и символы переноса строки.
str.find(sub, start) — ищет подстроку sub в строке, начиная с позиции start (возвращает -1, если не найдено).
list.append() — добавляет элемент в список.
' '.join(map(str, list)) — преобразует список чисел в строку с разделителем-пробелом.
## Алгоритм:
1)получение данных
2)инициализация
3)поиск в цикле.
4)вывод результатов
## Ошибки: 1) неправильный подсчет результатов, из-за того, что не было указано, что следующее вхождение t в s необходимо искать с учетом уже найденных, то есть не находить бесконечно одно и то же. исправление: index = s.find(t, index + 1)
2) невнимание к разнице между "с" и "С". исправление: использование по умолчанию верхнего регистра
## Вывод: написанная программа обрабатывает вводимые ДНК-последовательности и выводит правильное количество позиций подстроки t в строке s в формате чисел через пробел.
